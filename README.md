[Alle SCORM-Downloads](Downloads/README.md). In Moodle jede ZIP als eigene SCORM-Aktivität importieren. Für eine lokale Vorschau im Repository-Stamm `python -m http.server 8000` starten und die gewünschte Übung im Browser öffnen.

`python tools/master.py check --archives` prüft die SCORM-Pakete gegen die Master. `python tools/master.py export --all` aktualisiert die Exporte.
